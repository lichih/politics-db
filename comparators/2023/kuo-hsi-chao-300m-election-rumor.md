# Comparator：2023 郭璽重述「趙少康私吞3億元競選結餘款」案

## Case ID
2023-12-kuo-hsi-chao-300m-rumor

## Comparator strength
**strong — prior-debunking / initial non-prosecution comparator**

## 核心事實
2023總統大選期間流傳「趙少康私吞1994年台北市長競選結餘款3億元，遭王建煊譴責後退出新黨」。

台灣事實查核中心於2023-12-01發布查核：
- 趙少康1994年競選經費結餘約1040萬元；
- 選舉補助款約1260萬元；
- 兩者合計最多約2300萬元，不可能有「3億元結餘款」；
- 趙之後仍在新黨活動，王建煊亦與其合作；
- 判定傳言為「錯誤」。

郭璽於2023-12-07在網路節目仍表示「趙少康私吞83年台北市長競選結餘款3億元」等內容。

趙少康提告總統副總統選罷法意圖使人不當選及加重誹謗。

## 檢方第一次處理
北檢認為：
- 郭璽稱其依據王建煊在另一節目的發言；
- 非全然憑空捏造；
- 難認具有惡意傳播不實之事的犯意。

因此不起訴。

趙少康聲請再議後，2024-05-29高檢署認為原偵查「有不完備之處」，發回北檢續查。

## 與2026信民案的比較價值
1. 都是在正式選舉期間針對候選人散布具體可驗證事項。
2. 「3億元」傳言在郭璽發言前6天已有公開、具資料基礎的事實查核判定錯誤。
3. 被害候選人已提告。
4. 即使如此，北檢第一次仍不起訴，後由高檢署以調查不完備發回。

這可用於比較檢調介入與「明知／重大輕率」的門檻：
**同樣已有明確反證，為何一案先不起訴、需要再議補查；另一案則貼文當天即搜索、約談、扣押手機？**
