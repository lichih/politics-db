# Comparator：2022 周玉蔻／蔡玉真「張淑娟晶華緋聞」案

## Case ID
2022-09-zhou-tsai-chang-election-comparator

## 為何列為本案的雙標比較候選
此案發生在2022台北市長選舉期間。周玉蔻、蔡玉真於電視節目及社群平台指稱前中國小姐張淑娟為蔣孝嚴「晶華飯店緋聞案」女主角，並藉此延伸討論當時台北市長候選人蔣萬安的家族身世與選舉議題。

法院後來認定相關指摘並非事實，且未經合理查證；NCC相關行政訴訟資料亦確認節目是在選前期間把該緋聞與蔣萬安、選舉議題連結，造成不正確認知。

然而目前查得的公開刑事起訴與法院判決資料，罪名是：
- 刑法加重誹謗；
- 個人資料保護法非法利用個資。

**截至2026-10-04，本次公開資料查詢未看到檢方以公職人員選舉罷免法第104條起訴本案。**

這點具有比較價值：第104條並非告訴乃論；即使被害人張淑娟主要是以名譽、個資受害人身分提告，檢察官仍可依職權判斷是否另涉選舉不實訊息。

## 已確認事實
- 事件時間：2022年9月，正值九合一選舉期間。
- 當時蔣萬安是國民黨台北市長候選人。
- 周玉蔻、蔡玉真在節目及臉書指稱張淑娟是蔣孝嚴緋聞案女主角。
- 張淑娟於2022年9月底提告。
- 北檢於2023-07-05依加重誹謗、個資法等罪起訴。
- 台北地院於2024-11-26認定相關指摘並非事實、未合理查證，判兩人有罪。
- 2026-09-29二審高院仍認定有罪，周玉蔻9月、蔡玉真6月（可上訴）。

## 與2026信民案的異同

### 相同／可比
1. 均在選舉期間。
2. 均是公開散布具體事實性內容，不只是價值評論。
3. 均涉及可傷害他人名譽或社會評價的內容。
4. 均與特定候選人的選舉利益存在明確脈絡連結。
5. 後續司法或當事人供述已對「不實」提供強證據。

### 差異／需保留
1. 信民案的發文者直接承認「根本沒有那通電話」，主觀捏造證據較直接。
2. 張淑娟本人不是候選人；第104條若要成立，仍需證明散布行為具有使蔣萬安不當選的特定意圖。
3. 本比較目前能確定的是「公開起訴／判決未見104條」，不能僅靠查不到就斷言檢方從未內部評估或偵查104條。

## 執法差異觀察
- 信民案：貼文當日即搜索、約談、扣押手機並以104條偵辦。
- 張淑娟案：公開資料顯示由張淑娟提告後進入刑事程序；最終起訴罪名未見104條。
- 因此可提出「執法一致性」問題，但資料庫應標示為 comparator / possible disparity，而非直接寫成已證明司法雙標。
